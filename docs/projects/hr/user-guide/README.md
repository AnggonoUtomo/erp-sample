# Ebook Panduan Penggunaan HR

Folder ini berisi panduan operasional untuk pengguna pemula modul HR.

## Urutan baca

1. [Ebook PDF](panduan-penggunaan-modul-hr.pdf) — versi siap dibaca/dicetak.
2. [Sumber HTML](panduan-penggunaan-modul-hr.html) — sumber yang dapat diperbarui ketika menu atau alur HR berubah.
3. [HR Module Guide](../module-guide.md) — panduan teknis untuk programmer.
4. [Employee Contracts](../employee-contracts/README.md) — specification dan lifecycle kontrak yang lebih teknis.

## Memperbarui PDF

Ubah sumber HTML, lalu render ulang dengan browser Chromium dalam mode headless. Isi ebook harus selalu diperiksa terhadap module, field, dan relasi yang benar-benar tersedia di project.
