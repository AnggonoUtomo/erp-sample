# Template Inti Paket Work Item

Salin seluruh file dalam direktori ini ke folder work item baru, lalu tambahkan seluruh file dari template jenis pekerjaan yang sesuai. Template jenis yang mempunyai nama sama boleh menggantikan file shared karena lebih spesifik.

Setiap instance wajib mempunyai plan, task, backlog, konteks, deviasi, evidence, review, dan completion. Placeholder wajib diganti sebelum status `ready`.
