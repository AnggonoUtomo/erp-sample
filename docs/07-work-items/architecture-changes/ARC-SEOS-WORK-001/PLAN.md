# Rencana Kerja — ARC-SEOS-WORK-001

## Outcome

SEOS mempunyai satu aturan operasional yang memastikan setiap pekerjaan berada dalam satu folder kanonis dengan plan, task, backlog, pra-kerja, dan pascakerja yang perannya tidak tumpang tindih.

## Urutan

1. Audit setiap file dokumentasi dan bukti kode yang relevan.
2. Catat serta setujui proposal reusable.
3. Perbarui governance, indeks, dan template inti.
4. Tandai sumber paralel/konflik sebagai superseded tanpa menghapus bukti.
5. Siapkan backlog temuan di luar scope.
6. Verifikasi struktur, status, Markdown, path, dan diff.
7. Lengkapi evidence, review, completion, dan baseline sync.

## Guardrail

- tidak mengubah kode aplikasi;
- tidak mengaktifkan task aplikasi;
- tidak memperbaiki seluruh baseline lama secara massal;
- tidak menghapus bukti keputusan lama;
- tidak menggandakan status work item di backlog.

## Rollback

Perubahan hanya berupa Markdown dan dapat direvert per work item. Dokumen historis tidak dipindahkan atau dihapus.
