# ID Conventions

| Prefix | Makna | contoh |
|---|---|---|
| `REQ` | requirement | `REQ-ACL-001` |
| `BR` | bisnis aturan | `BR-FIN-002` |
| `BC` | Boundary | `BC-ACL-001` |
| `MOD` | Module | `MOD-ACL-AUT` |
| `FTR` | fitur | `FTR-ACL-003` |
| `BUG` | bug | `BUG-ACL-014` |
| `REF` | refactor | `REF-CORE-004` |
| `INT` | Integrasi | `INT-PAY-001` |
| `MIG` | data migrasi | `MIG-STD-002` |
| `UPG` | dependensi upgrade | `UPG-PHP-003` |
| `SEC` | keamanan perubahan/review | `SEC-ACL-005` |
| `PERF` | performa pekerjaan | `PERF-API-002` |
| `DEP` | Deprecation/removal | `DEP-API-001` |
| `INC` | insiden | `INC-PROD-007` |
| `ARC` | Arsitektur perubahan | `ARC-ACL-001` |
| `ADR` | Arsitektur keputusan | `ADR-0012` |
| `CTR` | Boundary/API kontrak | `CTR-ACL-004` |
| `EVT` | Event | `EVT-ACL-009` |
| `TSK` | Task | `TSK-ACL-001-02` |
| `TST` | pengujian case | `TST-ACL-020` |
| `DEV` | Deviation | `DEV-ACL-003` |
| `DOC-PROP` | dokumentasi proposal | `DOC-PROP-002` |
| `BL` | baseline snapshot | `BL-2026-001` |

ID adalah stabil dan jangan pernah reused. Human-readable names boleh perubahan; ID tidak.
